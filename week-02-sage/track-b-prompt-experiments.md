# Track B: Prompt Crafting & Iterations

## Goal
Improve and document prompt quality by refining prompts and showing versions.

---

## Prompt Experiment 1: Explain AI to a beginner

**Prompt v1**
Explain AI simply.


**Notes**
- Too vague, output was generic.
- Lacked audience context.

**Prompt v2**
Explain artificial intelligence to someone who hates tech in under 100 words.


**Notes**
- Better structure, shorter.
- More tailored.

**Prompt v3**
Explain artificial intelligence in a friendly way to a non-technical college student under 100 words.


**Result & Reflection**
- Output was clear, engaging.
- Tone and audience matter.

---

## Prompt Experiment 2: Project Plan

**Prompt v1**
Generate a learning plan for GitHub.


**Prompt v2**
Generate a 30-day plan to learn GitHub basics, with daily tasks under 20 minutes.


**Prompt v3**
Generate a 30-day beginner GitHub learning plan with specific tasks under 20 minutes each and links to relevant resources.


**Reflection**
- Adding constraints made output more actionable.

---

## Prompt Experiment 3: Kevin Persona Refinement

**Prompt v1**
Kevin, help me with GitHub.


**Prompt v2**
Kevin from IT, please explain how to set up a GitHub repo for SAGE.


**Prompt v3**
Kevin from IT (friendly and patient) — summarize how to set up a GitHub SAGE workspace with branches, issues, and PRs.


**Reflection**
- Persona + context → better teaching tone.

---

## Summary

Prompt refinement makes AI output:
- More relevant
- Better tone
- More actionable
