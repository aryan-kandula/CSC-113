# Project Ideation - Aryan Kandula

## Idea 1: Smart Coding Study Assistant

**Problem/Goal:**
Sometimes it’s hard to understand coding concepts just from lectures or notes. This project would create an AI assistant that explains programming topics in simple terms, gives examples, and even helps debug small errors in code.

**AI Tool(s):**
ChatGPT API, GitHub Copilot

**Why This Interests Me:**
As a Computer Science student, I regularly run into problems while learning new topics. Having a personalized AI assistant would make learning faster and less frustrating.

**Rough Scope:**
2–3 weeks

## Idea 2: AI Commit Message Generator

**Problem/Goal:**
Writing clear and professional commit messages can be confusing, especially when working on multiple files. This project would use AI to generate clean commit messages based on the changes made in the code.

**AI Tool(s):**
ChatGPT API, Git CLI

**Why This Interests Me:**
I use GitHub daily, and sometimes my commit messages are not as clear as they should be. This tool would improve my workflow and help me maintain better project quality.

**Rough Scope:**
1–2 weeks

---

## Idea 3: Daily Learning Log Generator

**Problem/Goal:**
It’s easy to forget what you learned each day, especially when studying multiple topics. This project would allow users to input what they learned, and AI would generate a clean, structured summary for GitHub or personal notes.

**AI Tool(s):**
ChatGPT, simple web app (HTML/CSS/JavaScript or Django)

**Why This Interests Me:**
I want to stay consistent with daily learning updates on GitHub. This tool would make it easier to track progress and build a strong learning history.

**Rough Scope:**
2–3 weeks
