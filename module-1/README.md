# CSC-113 Module 1: "Hello, Scholars!"  

Welcome to **Module 1** of CSC-113! This week focuses on getting set up for success: establishing your **GitHub account**, discovering the **AI tools** you already use, and connecting with classmates.  

## Key Activities
- Create a professional **GitHub account** and your first repository  
- Complete an **AI tools inventory**  
- Connect with classmates on the **discussion board**  
- Set up **at least one AI assistant** to help with learning  

## Time Investment
Approximately **2 hours**

## Pro Tips
- Keep your AI assistant handy to **learn workflows and solve problems**  
- Refresh GitHub if something breaks — it’s forgiving, and learning is part of the process
